# M2: Implementation & Baseline Development

## Overview
Complete production-ready implementation of the Bayesian Network framework with PC Algorithm, parameter learning, inference, and baseline methods.

## Contents
- **Code/**: Python implementation (~1000 lines)
  - PC Algorithm (4-phase constraint-based structure learning)
  - Parameter Learning (OLS with 95% confidence intervals)
  - Belief Propagation (exact inference)
  - 5 baseline methods (LR, RF, GB, DT, NN)
- **Reports:** Implementation details and technical specifications
- **Presentations:** 22-slide technical presentation

## Code Structure
- `pc_algorithm.py` - Structure learning
- `parameter_learning.py` - Parameter estimation
- `inference.py` - Belief Propagation
- `baselines.py` - Baseline methods
- `data_pipeline.py` - Data preprocessing
- `main.py` - Pipeline orchestrator
